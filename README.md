# snow-tools
# ❄️ SNOW TOOLS

Snow Manを応援するためのファンメイドツール集です。

## Tools

🚧 STORE CHECK（開発中）

複数の販売店がOricon・Billboard JAPANの集計対象かどうかを検索できます。

---

🚧 StreamDesk

複数端末・複数ストリーミングサービスの利用状況を管理します。

---

🚧 PLAYLIST LAB

楽曲やプレイリストを探しやすくするツールです。

---

🚧 SNOW MINUTES

3分・5分・10分など、空いた時間にできる応援を提案します。

---

🚧 BINGO

毎日の応援をゲーム感覚で楽しめるBINGOです。
